# Günlük

Her gün ne çalıştığımı ve ne öğrendiğimi yazdığım kişisel günlük.

Yazılar `gunluk` klasöründe markdown dosyası olarak duruyor. Dosya adı tarih, ilk satır başlık. `build.js` bunları okuyup `dist` içine düz HTML üretiyor. Vercel de bunu yayınlıyor.

Yeni yazı açmak için:

```
node yeni.js "Başlık"
```

Sonra dosyayı doldurup gönderiyorum, gerisi kendiliğinden oluyor.
